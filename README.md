# Zumra Siddique — Flutter Developer Portfolio

Professional portfolio website for Zumra Siddique (Flutter Developer, Lahore).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Edit content

Update profile, experience, skills, and projects in:

`src/data/content.ts`

Project screenshots live in:

`public/projects/expense/`
`public/projects/school/`
`public/projects/pos/`
